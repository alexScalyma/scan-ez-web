What is Scan-EZ

一部手机，两端引擎：
消费者手中的"验真器"，品牌手中的"雷达"

Scan-EZ 由端侧 SDK 与云端风控引擎组成。端侧负责"看得清"——把隐形信息稳定读出来；云端负责"看得透"——把每一次扫码变成风险研判与数据资产。

端侧 SDK

ON-DEVICE SDK · 看得清
抗抖动识别引擎——行走中、单手、远距离均可稳定识读
弱光增强——酒吧、仓库、夜间场景不失效
畸变矫正——瓶身弧面、褶皱标签、倾斜角度照样读取
离线缓存验证——无网络也能先验真，联网后同步

云端风控引擎

Core Advantages

六大核心优势

不是又一个扫码工具，而是一套从识别、互动、数据到执法取证的完整风控体系。

ADV-01

手机即检测仪

无需专用设备、无需培训：任何主流手机都是验真终端，防伪能力第一次真正到达每一位消费者。

ADV-02

验真即取证

每一次扫码自动留存时间、位置、设备指纹与结果——海量消费者在无意间成为品牌的"取证员"。

防伪是底线，互动是增量：会员、积分、复购、裂变都在同一次扫码里完成。

Data Collection

每一次扫码，沉淀六维数据

数据在采集端脱敏、在云端加密，既满足监管合规，又能支撑从渠道到刑侦的全链路分析。

TIME
时间维度扫码时间、频次、间隔规律——正常消费与"扫库"行为截然不同
GEO
地理维度扫码位置与流通路径比对，窜货与异地假货当场现形
DEVICE
设备维度设备指纹、机型、模拟器/改机识别——批量造假设备一网打尽
BATCH
批次维度哪一批次被扫、在哪被扫、真假比例——产线与渠道双向追溯
USER
用户维度会员画像、复购周期、区域偏好，反哺营销决策
RISK
风险维度0–100 实时评分 + 关联图谱，风险事件自动升级推送

Admin Console

后台指挥中心：品牌的"风控作战室"

一屏总览全渠道健康度，一键下发处置指令。后台不只是看板，而是可以行动的指挥系统。

CONSOLE-01

告警与工单

假码聚集地识别

设备指纹聚类

批量验证假货的"工作机"会形成异常设备簇：同机型高频扫码、模拟器特征、改机痕迹——顺着设备揪出造假作坊。

输出 → 设备簇图谱 · 作坊规模估算

时间线回溯
